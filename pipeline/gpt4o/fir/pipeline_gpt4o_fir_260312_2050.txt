To optimize the FIR filter code for an FPGA-CPU hybrid platform using task pipelining, we can break the FIR filter function into distinct stages and represent each stage as a separate function. We'll use High-Level Synthesis (HLS) pragmas to guide the process. For simplicity and clarity, let's define the stages as follows:

1. **Shift Stage:** This stage will handle the data shifting in the delay line.
2. **Compute Stage:** This stage calculates the result by performing the dot product.

We'll use #pragma directives to facilitate task pipelining. In an actual HLS environment, these pragmas would be used to enable parallelism and pipeline the execution of different stages across different data inputs.

Here's the refactored code:

```cpp
#include <stdio.h>
#include "fir.h"

// Function to handle shifting in the delay line
void shift_delay_line(int input, int delay_line[NUM_TAPS]) {
    #pragma HLS INLINE
    for (int i = NUM_TAPS - 1; i > 0; i--) {
        delay_line[i] = delay_line[i - 1];
    }
    delay_line[0] = input;
}

// Function to compute the dot product with taps
int compute_dot_product(int delay_line[NUM_TAPS], int taps[NUM_TAPS]) {
    #pragma HLS INLINE
    int result = 0;
    for (int i = 0; i < NUM_TAPS; i++) {
        result += delay_line[i] * taps[i];
    }
    return result;
}

// Top-level FIR function
void fir(int input, int *output, int taps[NUM_TAPS]) {
    #pragma HLS DATAFLOW
    
    static int delay_line[NUM_TAPS] = {};
    
    shift_delay_line(input, delay_line);
    *output = compute_dot_product(delay_line, taps);
}

int main() {
    int taps[NUM_TAPS] = {1, 2, 2, 1};  // simple low-pass coefficients
    int output;

    for (int i = 0; i < 100000000; i++) {
        fir(i % 256, &output, taps);
    }

    printf("Last output: %d\n", output);
    return 0;
}
```

### Explanation

- **Shift Stage:** Implemented by the `shift_delay_line` function, which updates the delay line by shifting its contents to the right and inserting the new input at the beginning. This follows the first example where each iteration of the loop is treated as a stage.

- **Compute Stage:** Implemented by the `compute_dot_product` function, which computes the dot product of the delay line and taps array.

- **Dataflow Directive:** The `#pragma HLS DATAFLOW` directive is used in the top-level `fir` function to indicate that the stages should be pipelined, allowing for concurrent execution of these stages on different datasets.

By structuring the code this way, we allow the HLS toolchain to pipeline the execution of different stages of the FIR filter, increasing throughput and utilizing the parallel execution resources of the FPGA more effectively.
