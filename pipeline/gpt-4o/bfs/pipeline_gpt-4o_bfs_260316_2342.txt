1. **Initialization Stage**:
   - `init_bfs` initializes the structures and state needed for BFS, including the queue, levels, and level counts. This function sets up the initial conditions before any traversal begins.

2. **Queue Traversal Stage**:

3. **Neighbor Processing Stage**:
   - `process_neighbors` checks each neighbor of the current node, updating levels and queue. This step is the most critical for exploiting parallelism because multiple nodes can be processed simultaneously, which is why it has been isolated.

4. **Data Interfaces**:
   - The parameter passing between functions ensures minimal data movement and facilitates task pipelining. Instead of recalculating indices or conditions, each function is handed the relevant data for processing.

#define Q_PUSH(node) { queue[q_in == 0 ? N_NODES - 1 : q_in - 1] = node; q_in = (q_in + 1) % N_NODES; }

void bfs(node_t nodes[N_NODES], edge_t edges[N_EDGES],
         node_index_t starting_node, level_t level[N_NODES],
         edge_index_t level_counts[N_LEVELS]) {

    node_index_t q_in, q_out;
    node_index_t dummy;
    node_index_t n;
    edge_index_t e;

    q_in  = 1;
    q_out = 0;
    level[starting_node] = 0;
    level_counts[0] = 1;
    Q_PUSH(starting_node);

    loop_queue: for (dummy = 0; dummy < N_NODES; dummy++) {
        if (Q_EMPTY())
            break;
